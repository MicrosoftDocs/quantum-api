# Q\# and QDK Python library API reference

This API reference includes the Q# standard library and Python libraries for developing quantum programs with the Microsoft Quantum Development Kit (QDK) and the Azure Quantum service.

- [Q# library](xref:Microsoft.Quantum.apiref-toc): The standard Q# library.
- [Python library](/python/qdk/qdk): The `qdk` Python package.
- [REST APIs](/rest/api/azurequantum/): The Azure Quantum REST APIs that allow you to develop clients that use REST calls to work with the service.
- [ARM templates](/azure/templates/microsoft.quantum/workspaces?tabs=bicep&pivots=deployment-language-arm-template): Deploy an Azure Quantum workspace using ARM, Bicep, or Terraform in your template.
